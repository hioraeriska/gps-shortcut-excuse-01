A make.fun entry for [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): a program that writes the GPS's one-line excuse for sending the driver down the wrong road.

Run `node main.ts` — it writes the excuse to `entry.txt` in the output directory.
